## 스레드(Threads)란 무엇인가요?

스레드(Threads)는 메타(Meta, 구 페이스북)가 2023년 7월에 출시한 텍스트 기반 소셜 미디어 서비스입니다. 인스타그램 계정과 연동되어 간편하게 가입할 수 있으며, 짧은 글과 링크, 사진, 영상을 게시할 수 있습니다. 트위터(현 X)의 대안 서비스로 주목받으며 출시 초기 빠른 속도로 사용자를 모았습니다.

2026년 현재 스레드는 전 세계 수억 명의 월간 활성 사용자를 보유하고 있으며, 한국에서도 많은 연예인, 인플루언서, 브랜드가 활발하게 활동하고 있습니다.

스레드의 주요 특징은 다음과 같습니다.

- 최대 500자의 텍스트 게시물 작성 가능
- 최대 10장의 사진 또는 최대 5분의 동영상 첨부 가능
- 인스타그램 팔로워 기반으로 손쉬운 네트워크 구축
- 오픈소셜 프로토콜(ActivityPub) 지원으로 다른 플랫폼과 연동 가능

## 스레드 앱 설치 및 가입 방법

### 앱 설치

1. 앱스토어(아이폰) 또는 구글 플레이스토어(안드로이드)를 엽니다.
2. 검색창에 '스레드' 또는 'Threads'를 입력합니다.
3. 메타(Meta)에서 개발한 'Threads' 앱을 찾아 설치합니다.
4. 설치가 완료되면 앱을 실행합니다.

### 인스타그램 계정으로 가입

스레드는 인스타그램 계정 없이는 가입할 수 없습니다. 인스타그램 계정이 없다면 먼저 인스타그램에 가입한 뒤 스레드를 사용할 수 있습니다.

1. 스레드 앱을 실행하면 '인스타그램으로 로그인' 버튼이 나타납니다.
2. 버튼을 탭하면 인스타그램 앱(또는 인스타그램 웹)으로 이동해 로그인 확인 절차가 진행됩니다.
3. 인스타그램 사용자 이름과 비밀번호를 입력하거나, 이미 로그인되어 있다면 계정 선택 화면이 나타납니다.
4. 사용할 계정을 선택하고 '스레드에서 계속'을 탭합니다.

### 프로필 설정

1. 가입 후 첫 화면에서 프로필 사진, 소개 문구, 링크를 설정하는 단계가 나타납니다.
2. '인스타그램에서 가져오기'를 선택하면 인스타그램 프로필 정보를 그대로 불러올 수 있습니다.
3. 직접 입력하려면 각 항목을 탭해 수정합니다.
4. 소개 문구는 최대 150자까지 작성할 수 있습니다.
5. 설정을 마치면 '스레드 가입'을 탭합니다.

### 공개 계정 vs 비공개 계정 선택

가입 중에 '공개 프로필' 또는 '비공개 프로필'을 선택하는 화면이 나옵니다.

- **공개 프로필**: 누구나 내 게시물을 볼 수 있고, 팔로우 신청 없이 팔로우할 수 있습니다.
- **비공개 프로필**: 팔로우 요청을 승인해야만 내 게시물을 볼 수 있습니다.

나중에 설정에서 언제든지 변경할 수 있습니다.

## 스레드 기본 사용법

### 게시물 작성하기

1. 화면 하단 가운데의 연필 아이콘(새 스레드) 버튼을 탭합니다.
2. 텍스트 입력창이 열리면 최대 500자의 내용을 작성합니다.
3. 사진이나 영상을 추가하려면 텍스트창 하단의 사진 아이콘을 탭합니다.
4. 갤러리에서 원하는 파일을 선택하거나 직접 촬영해 첨부합니다.
5. 링크를 본문에 직접 붙여넣으면 미리보기 카드가 자동으로 생성됩니다.
6. 게시물 하단 왼쪽의 '답글 허용 대상'을 탭해 모든 사람, 팔로우하는 사람, 언급한 사람 중 선택할 수 있습니다.
7. 작성이 완료되면 오른쪽 상단의 '게시' 버튼을 탭합니다.

### 스레드 체인(연속 게시) 작성

스레드는 여러 게시물을 체인처럼 연결해서 긴 이야기를 이어 쓸 수 있습니다.

1. 게시물 작성 화면에서 본문 입력 후 하단의 '스레드 추가'를 탭합니다.
2. 이어지는 내용을 입력합니다.
3. 스레드를 더 추가하려면 다시 '스레드 추가'를 탭합니다.
4. 모두 작성했으면 '모두 게시'를 탭해 체인 전체를 한 번에 올립니다.

### 피드 탐색하기

- **홈 피드(집 모양 아이콘)**: 내가 팔로우한 계정의 게시물과 추천 콘텐츠가 보입니다.
- **검색(돋보기 아이콘)**: 특정 사용자나 키워드로 검색합니다.
- **알림(종 모양 아이콘)**: 내 게시물의 좋아요, 댓글, 새 팔로워 알림을 확인합니다.
- **프로필(사람 모양 아이콘)**: 내 프로필과 게시물 목록을 확인합니다.

### 좋아요, 댓글, 공유, 리포스트

게시물 하단에는 네 가지 인터랙션 버튼이 있습니다.

- **하트(좋아요)**: 탭하면 게시물에 좋아요를 누릅니다. 다시 탭하면 취소됩니다.
- **댓글(말풍선)**: 해당 게시물에 답글을 작성합니다.
- **리포스트(화살표)**: 다른 사람의 게시물을 내 프로필에 그대로 공유하거나, 자신의 코멘트를 추가해 인용 게시할 수 있습니다.
- **공유(종이비행기)**: 외부 앱(카카오톡, 문자 등)으로 게시물 링크를 공유하거나, 인스타그램 스토리에 공유할 수 있습니다.

## 팔로우 및 추천 계정 찾기

### 인스타그램 팔로워 불러오기

스레드에 가입한 직후 인스타그램에서 팔로우하는 사람들 중 스레드에도 가입한 계정 목록이 자동으로 표시됩니다. '모두 팔로우'를 탭하면 한 번에 모두 팔로우할 수 있고, 개별적으로 선택해서 팔로우할 수도 있습니다.

### 검색으로 팔로우 찾기

1. 검색 탭(돋보기)을 탭합니다.
2. 검색창에 팔로우하고 싶은 사람의 이름이나 아이디를 입력합니다.
3. 결과 목록에서 해당 계정을 찾아 '팔로우' 버튼을 탭합니다.

### 관심 주제로 계정 찾기

검색 탭의 상단에는 인기 주제 태그나 트렌딩 게시물이 표시됩니다. 관심 있는 주제를 탭하면 관련 게시물과 계정을 탐색할 수 있습니다.

## 개인정보 및 알림 설정

### 알림 설정 조정

1. 프로필 탭(오른쪽 하단) → 오른쪽 상단 메뉴(가로 두 줄 아이콘) → '설정 및 개인정보'를 탭합니다.
2. '알림'을 선택합니다.
3. 좋아요, 댓글, 팔로우 요청, 언급 등 각 알림 유형별로 켜고 끌 수 있습니다.

### 특정 계정 차단 및 뮤트

- **차단**: 상대방 프로필 → 오른쪽 상단 세 점 메뉴 → '차단'. 차단하면 상대방이 내 게시물을 볼 수 없고 나도 상대방 게시물이 보이지 않습니다.
- **팔로우 취소**: 팔로우 중인 계정에서 '팔로잉' 버튼 탭 → '팔로우 취소'.
- **뮤트**: 상대방 게시물의 세 점 메뉴 → '뮤트'. 팔로우는 유지하면서 피드에서 게시물을 숨길 수 있습니다.

### 댓글 필터링 설정

1. 설정 → '개인정보' → '숨겨진 단어'로 이동합니다.
2. '사용자 지정 단어 및 문구'에 원하지 않는 단어를 추가하면 해당 단어가 포함된 댓글이 자동으로 필터링됩니다.
3. '고급 댓글 필터링'을 활성화하면 욕설이나 스팸성 댓글이 자동으로 숨겨집니다.

## 스레드 계정 관리

### 인스타그램과의 연동 관리

스레드 계정은 인스타그램 계정과 연결되어 있으므로 인스타그램 비밀번호를 변경하면 스레드에도 동일하게 적용됩니다. 인스타그램을 탈퇴하면 스레드 계정도 함께 삭제됩니다.

### 스레드 계정 비활성화

스레드만 일시적으로 사용 중지하고 싶다면 계정을 비활성화할 수 있습니다.

1. 프로필 → 설정 → '계정'으로 이동합니다.
2. '계정 비활성화'를 탭합니다.
3. 비활성화 기간 동안 내 프로필과 게시물이 다른 사용자에게 보이지 않습니다.
4. 다시 로그인하면 즉시 재활성화됩니다.

### 스레드 계정 삭제

스레드 계정을 완전히 삭제하려면 인스타그램 계정을 유지하면서 스레드만 삭제할 수 있습니다.

1. 프로필 → 설정 → '계정' → '계정 삭제'로 이동합니다.
2. 삭제 사유를 선택하고 비밀번호를 입력해 인증합니다.
3. '삭제' 버튼을 탭하면 30일 이내에는 계정을 복구할 수 있으며, 30일이 지나면 영구 삭제됩니다.

## 자주 묻는 질문(Q&A)

**Q. 스레드에서 인스타그램 팔로워에게 자동으로 알림이 가나요?**

A. 스레드에 가입하면 인스타그램 팔로워에게 가입 알림이 발송될 수 있습니다. 원하지 않는다면 가입 직후 설정 → 알림 → '스레드 가입 알림'을 끄거나, 가입 전 인스타그램 계정을 비공개로 설정하는 방법이 있습니다.

**Q. 스레드에 올린 게시물을 인스타그램에도 공유할 수 있나요?**

A. 게시물 작성 후 공유 버튼을 통해 인스타그램 스토리나 피드에 공유할 수 있습니다. 단, 스레드와 인스타그램은 별개의 피드를 운영하므로 자동 동기화는 되지 않습니다.

**Q. PC(웹 브라우저)에서도 스레드를 사용할 수 있나요?**

A. 네, threads.net에 접속해 웹 브라우저에서도 스레드를 사용할 수 있습니다. 인스타그램 계정으로 로그인하면 모바일 앱과 동일한 기능을 이용할 수 있습니다.

**Q. 해시태그 기능이 없나요?**

A. 스레드는 전통적인 해시태그 대신 특정 주제 태그 기능을 제공합니다. 게시물 작성 시 '#주제'를 입력하면 해당 주제로 묶인 게시물들을 함께 탐색할 수 있습니다.

**Q. 스레드 계정이 해킹된 것 같아요.**

A. 즉시 인스타그램 앱에서 비밀번호를 변경하고 이중 인증을 활성화하세요. 인스타그램 설정 → 보안 → 2단계 인증에서 설정할 수 있습니다. 스레드 계정 보안은 인스타그램 보안 설정에 따라 동일하게 적용됩니다.

## 정리

스레드는 인스타그램 계정 하나로 간편하게 시작할 수 있는 텍스트 중심의 소셜 미디어입니다. 짧은 일상 공유, 생각 정리, 관심사 기반의 대화에 적합하며, 인스타그램 팔로워 네트워크를 바탕으로 빠르게 소통 범위를 넓힐 수 있습니다. 알림과 개인정보 설정을 꼼꼼히 조정해 나에게 맞는 환경을 만들고 편하게 활용해 보세요.
