## 윈도우 클립보드 기록이란?

컴퓨터를 사용하다 보면 복사(Ctrl+C)한 텍스트나 이미지가 새로운 복사 작업으로 덮어씌워져 이전에 복사했던 내용을 잃어버린 경험이 있으실 겁니다. **윈도우 클립보드 기록**은 이런 불편을 해소해주는 기능입니다.

윈도우 10(2018년 10월 업데이트 이후)과 윈도우 11에 기본 내장된 이 기능을 활성화하면, 복사한 내용을 최대 25개까지 기록으로 보관하고 필요할 때 꺼내 쓸 수 있습니다. 텍스트·이미지·HTML 등 다양한 형식을 지원하며, 핀(Pin) 기능으로 자주 쓰는 내용을 고정해 두는 것도 가능합니다.

이 글에서는 클립보드 기록 기능을 활성화하는 방법부터 실전 활용까지 자세히 안내합니다.

---

## 1단계: 클립보드 기록 기능 활성화하기

기본적으로 클립보드 기록은 꺼져 있습니다. 먼저 설정에서 켜야 합니다.

**방법 1 - 설정 앱에서 활성화 (윈도우 11 기준):**

1. 키보드에서 **Windows 키 + I** 를 동시에 눌러 **설정** 앱을 엽니다.
2. 왼쪽 메뉴에서 **시스템**을 클릭합니다.
3. 오른쪽 목록을 스크롤해 **클립보드**를 클릭합니다.
4. **클립보드 기록** 항목 아래의 토글 스위치를 클릭해 **켬(파란색)**으로 변경합니다.

**방법 2 - 단축키로 바로 활성화:**

1. 키보드에서 **Windows 키 + V** 를 누릅니다.
2. "클립보드 기록이 꺼져 있습니다"라는 팝업이 나타납니다.
3. 팝업 안의 **"켜기"** 버튼을 클릭하면 즉시 활성화됩니다.

> **팁:** 방법 2가 훨씬 빠릅니다. 기억하기 쉬운 단축키 **Win+V**로 바로 활성화해 보세요.

## 2단계: 클립보드 기록 창 열기 및 기본 사용법

활성화 후, 복사한 내용은 자동으로 클립보드 기록에 저장됩니다.

**클립보드 기록 창 열기:**
- 키보드에서 **Windows 키 + V** 를 누릅니다.
- 화면 우측 하단(또는 커서 근처)에 클립보드 기록 패널이 나타납니다.

**기록에서 붙여넣기:**
1. **Win+V**로 클립보드 기록 창을 엽니다.
2. 목록에서 붙여넣고 싶은 항목을 클릭합니다.
3. 선택한 항목이 현재 커서 위치에 자동으로 붙여넣어집니다.

**실전 예시:**
- 한글 문서 작성 중 여러 단락을 복사해두고, Win+V로 기록을 열어 원하는 단락을 선택해 붙여넣기
- 웹 서핑 중 여러 URL을 복사해두고 나중에 한꺼번에 붙여넣기
- 업무 중 자주 쓰는 이메일 서명이나 인사말을 고정해두고 빠르게 삽입하기

## 3단계: 클립보드 항목 고정(핀)하기

자주 사용하는 텍스트(이메일 주소, 주소, 자주 쓰는 문구 등)를 고정해두면 클립보드가 초기화되어도 사라지지 않습니다.

1. **Win+V**로 클립보드 기록 창을 엽니다.
2. 고정할 항목에 마우스를 올리면 우측에 **...** (더보기) 아이콘이 나타납니다.
3. **...** 를 클릭하면 메뉴가 펼쳐집니다.
4. **"고정"** (핀 아이콘)을 클릭합니다.
5. 해당 항목 옆에 핀 아이콘(📌)이 표시되며 고정 완료됩니다.

**고정된 항목의 특징:**
- PC를 재시작해도 사라지지 않습니다.
- 클립보드 기록을 전체 삭제해도 고정 항목은 유지됩니다.
- 고정 해제는 같은 방법으로 핀 아이콘을 다시 클릭하면 됩니다.

---

## 4단계: 클립보드 항목 삭제 및 전체 지우기

더 이상 필요 없는 복사 기록을 깔끔하게 정리할 수 있습니다.

**개별 항목 삭제:**
1. 클립보드 기록 창(Win+V)을 엽니다.
2. 삭제할 항목에 마우스를 올리고 **...** 를 클릭합니다.
3. **"삭제"** 를 선택하면 해당 항목만 제거됩니다.

**전체 기록 삭제:**
1. 클립보드 기록 창 우측 상단의 **"모두 지우기"** 버튼을 클릭합니다.
2. 고정된 항목을 제외한 모든 기록이 삭제됩니다.

> **보안 팁:** 비밀번호, 개인정보, 카드 번호 등 민감한 정보를 복사한 후에는 사용이 끝나는 즉시 해당 항목을 삭제하거나 전체 기록을 지우는 것이 좋습니다.

## 5단계: 클립보드 클라우드 동기화 설정하기 (선택 사항)

마이크로소프트 계정으로 로그인한 경우, 클립보드 기록을 여러 윈도우 PC 간에 동기화할 수 있습니다.

**동기화 활성화 방법:**
1. **설정 → 시스템 → 클립보드** 로 이동합니다.
2. **"여러 장치에서 동기화"** 항목을 찾습니다.
3. 토글을 켜고 **"자동으로 동기화"** 또는 **"고정된 항목만 동기화"** 중 하나를 선택합니다.

**자동으로 동기화:** 복사할 때마다 모든 항목이 클라우드에 업로드되어 다른 PC에서도 사용 가능합니다.  
**고정된 항목만 동기화:** 핀으로 고정한 항목만 동기화되어 보안에 더 유리합니다.

> **주의:** 클라우드 동기화를 켜면 복사한 내용이 마이크로소프트 서버에 전송됩니다. 업무상 기밀이나 개인정보가 포함될 수 있다면 '고정된 항목만 동기화' 또는 동기화 비활성화를 권장합니다.

---

## 6단계: 단축키 마스터하기

클립보드 관련 주요 단축키를 익혀두면 작업 속도가 크게 향상됩니다.

| 단축키 | 기능 |
|--------|------|
| Ctrl + C | 선택 항목 복사 |
| Ctrl + X | 선택 항목 잘라내기 |
| Ctrl + V | 붙여넣기 (최근 복사 항목) |
| **Win + V** | **클립보드 기록 창 열기** |
| Ctrl + Shift + V | 서식 없이 텍스트만 붙여넣기 (앱마다 다름) |
| Ctrl + A → Ctrl + C | 전체 선택 후 복사 |

> **꿀팁:** 웹 브라우저나 문서 작업 시, 서식이 함께 복사되는 것이 불편하다면 **메모장에 한 번 붙여넣기** 후 다시 복사하면 순수 텍스트만 남습니다. 또는 일부 앱에서는 Ctrl+Shift+V로 서식 없이 바로 붙여넣을 수 있습니다.

## 자주 묻는 질문(FAQ)

**Q. Win+V를 눌렀는데 아무것도 안 나와요.**
A. 클립보드 기록이 꺼져 있거나, 아직 아무것도 복사하지 않은 상태입니다. 팝업이 뜨면 '켜기'를 클릭하고, 그 후 Ctrl+C로 무언가를 복사한 뒤 다시 시도해보세요.

**Q. 이미지도 클립보드 기록에 저장되나요?**
A. 네, 복사한 이미지도 기록에 저장됩니다. 단, 이미지의 경우 클라우드 동기화는 지원되지 않으며, PC를 재시작하면 고정하지 않은 이미지 기록은 사라집니다.

**Q. 클립보드 기록이 최대 몇 개까지 저장되나요?**
A. 최대 25개 항목이 저장됩니다. 25개를 초과하면 가장 오래된 항목부터 자동으로 삭제됩니다. 단, 고정(핀)된 항목은 25개 제한에 포함되지 않습니다.

**Q. 엑셀이나 한글에서 복사한 표도 저장되나요?**
A. 네, 엑셀 셀 범위나 한글 표를 복사해도 클립보드 기록에 저장됩니다. 단, 복잡한 서식은 일부 앱에서 정상적으로 붙여넣기 되지 않을 수 있습니다.

**Q. 다른 사람이 내 클립보드 기록을 볼 수 있나요?**
A. 같은 PC의 윈도우 계정에서만 볼 수 있습니다. 다른 사용자 계정에서는 접근할 수 없습니다. 하지만 PC를 공유하거나 자리를 비울 때는 보안을 위해 기록을 지우는 것이 좋습니다.

**Q. 윈도우 10에서도 사용 가능한가요?**
A. 네, 윈도우 10 버전 1809(2018년 10월 업데이트) 이상에서 사용 가능합니다. 설정 → 시스템 → 클립보드에서 동일하게 활성화할 수 있습니다.

## 클립보드 기록 활용 실전 시나리오

**시나리오 1 - 여러 곳에서 정보 모아 붙여넣기**
보고서 작성 시 웹페이지 여러 곳에서 참고 문구를 Ctrl+C로 복사해두고, 작성 화면에서 Win+V를 눌러 목록에서 하나씩 골라 붙여넣으면 탭을 왔다 갔다 할 필요 없이 효율적입니다.

**시나리오 2 - 자주 쓰는 정보 고정해두기**
은행 계좌번호, 회사 주소, 이메일 서명, 자주 쓰는 답변 문구 등을 한 번 복사해 고정해두면, 언제든 Win+V로 빠르게 불러올 수 있습니다.

**시나리오 3 - 업무 중 실수 방지**
중요한 텍스트를 Ctrl+C로 복사해두고 다른 작업을 하다 덮어씌워진 경우, Win+V로 기록을 열어 이전 복사 항목을 복원할 수 있습니다.

## 정리

윈도우 클립보드 기록 기능은 한 번 사용하기 시작하면 없어서는 안 될 필수 기능입니다. **Win+V** 단축키 하나만 기억하면 되는 매우 간단한 기능이지만, 업무 효율을 크게 높여줍니다.

오늘 설명한 순서대로 ①기능 활성화 → ②Win+V로 기록 창 열기 → ③자주 쓰는 항목 고정하기만 해도 PC 작업 속도가 눈에 띄게 빨라집니다. 바로 Win+V를 눌러 시작해보세요!
