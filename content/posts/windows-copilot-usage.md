## 윈도우 코파일럿이란?

윈도우 코파일럿(Windows Copilot)은 마이크로소프트가 윈도우 11에 통합한 AI 어시스턴트입니다. OpenAI의 GPT 모델을 기반으로 하며, 윈도우 화면 오른쪽에 사이드바 형태로 열려 텍스트 질문, 파일 요약, PC 설정 변경, 이미지 생성 등 다양한 기능을 제공합니다.

2024년 이후 윈도우 업데이트를 통해 코파일럿 기능이 대폭 강화되어 2026년 현재는 작업표시줄에서 바로 실행하거나 단축키로 열 수 있으며, 마이크로소프트 365(오피스) 앱과도 긴밀하게 연동됩니다.

코파일럿으로 할 수 있는 주요 기능은 다음과 같습니다.

- 자연어로 PC 설정 변경 (다크 모드 켜기, 볼륨 조절, 블루투스 켜기 등)
- 웹 검색 결과를 요약해서 답변
- 클립보드 내용 또는 화면 내용 요약 및 분석
- 이미지 생성(Image Creator, DALL-E 기반)
- 문서, 이메일 작성 도움
- 수식 계산, 코드 설명 등 다양한 질문 응답

## 코파일럿 활성화 및 실행 방법

### 윈도우 업데이트 확인

코파일럿을 사용하려면 윈도우 11 22H2 이상 버전이 설치되어 있어야 합니다.

1. 시작 메뉴 → 설정(톱니바퀴 아이콘)을 클릭합니다.
2. 왼쪽 메뉴에서 'Windows 업데이트'를 선택합니다.
3. '업데이트 확인' 버튼을 클릭합니다.
4. 사용 가능한 업데이트가 있으면 다운로드 및 설치를 진행합니다.
5. 설치 후 PC를 재시작합니다.

### 코파일럿 실행 방법

업데이트 후에는 다음 세 가지 방법으로 코파일럿을 열 수 있습니다.

**방법 1: 작업표시줄 아이콘**
- 화면 하단 작업표시줄 오른쪽에 코파일럿 아이콘(회오리 모양 또는 C 아이콘)이 표시됩니다.
- 해당 아이콘을 클릭하면 오른쪽에서 코파일럿 사이드바가 열립니다.

**방법 2: 단축키**
- 키보드에서 `Windows 키 + C`를 누르면 코파일럿이 즉시 실행됩니다.
- 코파일럿을 닫을 때도 동일한 단축키를 누릅니다.

**방법 3: 시작 메뉴 검색**
- 시작 메뉴를 클릭하거나 `Windows 키`를 누릅니다.
- 검색창에 'Copilot'을 입력합니다.
- 검색 결과에서 'Copilot'을 클릭해 실행합니다.

### 작업표시줄에 코파일럿 아이콘이 없는 경우

1. 작업표시줄 빈 공간에서 마우스 오른쪽 버튼 클릭 → '작업 표시줄 설정'을 선택합니다.
2. '작업 표시줄 항목' 섹션에서 'Copilot(미리 보기)' 토글을 찾아 켭니다.
3. 설정 창을 닫으면 작업표시줄에 코파일럿 아이콘이 표시됩니다.

만약 해당 항목 자체가 없다면 윈도우 업데이트가 충분히 진행되지 않은 것입니다. 업데이트를 다시 확인하세요.

## 코파일럿 기본 사용법

### 텍스트로 질문하기

코파일럿 사이드바 하단의 입력창에 원하는 내용을 한국어로 자유롭게 입력하고 Enter를 누르거나 전송 버튼을 클릭합니다.

예시 질문:
- "오늘 서울 날씨 어때?"
- "엑셀에서 VLOOKUP 함수 사용법 알려줘"
- "아침에 먹기 좋은 간단한 레시피 추천해줘"
- "Python으로 리스트를 정렬하는 방법 코드로 알려줘"

코파일럿은 대화 맥락을 기억하므로 이전 답변에 이어서 추가 질문을 할 수 있습니다. 예를 들어 "방금 말한 레시피 재료를 간단히 목록으로 정리해줘"처럼 대화를 이어갈 수 있습니다.

### PC 설정 음성/텍스트로 제어

코파일럿의 강력한 기능 중 하나는 자연어로 PC 설정을 바꿀 수 있다는 점입니다.

다음과 같이 입력해 보세요.

- "다크 모드로 바꿔줘" → 화면 테마가 어두운 모드로 변경됩니다.
- "볼륨 50으로 낮춰줘" → 시스템 볼륨이 50%로 조절됩니다.
- "블루투스 켜줘" → 블루투스 설정이 활성화됩니다.
- "와이파이 꺼줘" → Wi-Fi가 비활성화됩니다.
- "스크린샷 찍어줘" → 화면을 캡처합니다.
- "집중 모드 켜줘" → 방해 금지 모드가 활성화됩니다.

설정 변경 전 코파일럿이 확인 메시지를 보여줄 수 있으며, '확인'을 클릭하면 실제 설정이 변경됩니다.

### 클립보드 내용 분석 및 요약

텍스트를 복사한 뒤 코파일럿에 붙여넣으면 내용 요약, 번역, 교정, 수정을 요청할 수 있습니다.

예를 들어 긴 영문 이메일을 복사해서 코파일럿 입력창에 붙여넣고 "이 내용을 한국어로 요약해줘"라고 입력하면 핵심 내용을 한국어로 정리해서 보여줍니다.

또는 자신이 작성한 한국어 문장을 붙여넣고 "맞춤법 교정해줘" 또는 "더 자연스럽게 다듬어줘"라고 요청할 수 있습니다.

## 이미지 생성 기능 사용법

코파일럿에는 DALL-E 기반의 이미지 생성 기능이 내장되어 있습니다. 원하는 이미지를 텍스트로 묘사하면 AI가 그림을 만들어 줍니다.

1. 코파일럿 입력창에 원하는 이미지를 설명합니다.
2. 예시: "바닷가에서 일몰을 바라보는 강아지 수채화 스타일로 그려줘"
3. 잠시 기다리면 생성된 이미지가 사이드바에 표시됩니다.
4. 생성된 이미지를 클릭하면 크게 볼 수 있고, 오른쪽 버튼으로 저장할 수 있습니다.

한국어 설명도 잘 인식하지만, 더 구체적이고 상세한 묘사를 입력할수록 원하는 결과에 가까운 이미지가 생성됩니다.

이미지 생성에는 마이크로소프트 계정에 부여된 크레딧이 사용됩니다. 매일 일정량의 무료 크레딧이 제공되며, 코파일럿 Pro 구독 시 더 많은 크레딧과 빠른 생성 속도를 사용할 수 있습니다.

## Microsoft 365와 연동 사용

마이크로소프트 365(구 오피스) 구독자라면 Word, Excel, PowerPoint, Outlook에서도 코파일럿 기능을 사용할 수 있습니다.

**Word에서 코파일럿**
- 문서 상단의 코파일럿 아이콘 클릭 → "이 문서를 세 줄로 요약해줘" 또는 "마케팅 기획서 초안 작성해줘" 등 지시.
- 빈 문서에서 시작할 때 "코파일럿으로 초안 작성" 버튼을 누르면 주제와 방향을 입력하는 창이 열립니다.

**Excel에서 코파일럿**
- 스프레드시트 데이터를 선택하고 코파일럿에 "이 데이터로 월별 매출 추이 차트 만들어줘" 또는 "가장 높은 값을 강조 표시해줘" 등 지시.
- 수식을 모를 때 "이 열의 값을 합산하는 수식 만들어줘"처럼 자연어로 요청하면 수식을 자동으로 제안합니다.

**Outlook에서 코파일럿**
- 받은 이메일 상단의 코파일럿 버튼 클릭 → "이 이메일의 핵심 요청 사항이 뭐야?" 요약 가능.
- 이메일 작성 창에서 "정중한 거절 이메일 초안 작성해줘" 등 요청 가능.

## 코파일럿 설정 및 개인화

### 대화 스타일 변경

코파일럿 상단에는 '균형감 있는', '창의적인', '정밀한' 세 가지 대화 스타일 옵션이 있습니다.

- **균형감 있는(Balanced)**: 정확성과 창의성의 균형을 맞춘 기본 모드입니다.
- **창의적인(Creative)**: 더 자유롭고 아이디어 중심의 답변을 생성합니다.
- **정밀한(Precise)**: 사실에 충실하고 간결한 답변을 생성합니다. 정확한 정보가 필요할 때 적합합니다.

### 대화 기록 삭제

코파일럿 대화 내용을 삭제하려면 입력창 위쪽의 '새 주제' 버튼(빗자루 아이콘)을 클릭합니다. 이전 대화 맥락이 초기화되며 새로운 대화가 시작됩니다.

## 자주 묻는 질문(Q&A)

**Q. 코파일럿을 사용하려면 마이크로소프트 계정이 필요한가요?**

A. 기본적인 질문과 답변은 계정 없이도 사용할 수 있지만, 이미지 생성이나 개인화 기능을 사용하려면 마이크로소프트 계정 로그인이 필요합니다. 코파일럿 사이드바 오른쪽 상단의 로그인 버튼을 클릭해 로그인하세요.

**Q. 코파일럿이 한국어를 잘 이해하나요?**

A. 네, 한국어로 질문해도 자연스럽게 한국어로 답변합니다. 다만 전문적이거나 복잡한 내용의 경우 영어로 질문하는 것이 더 정확한 답변을 받는 데 도움이 될 수 있습니다.

**Q. 코파일럿이 내 파일을 자동으로 읽나요?**

A. 코파일럿이 내 PC 파일에 자동으로 접근하지는 않습니다. 파일 내용을 분석하려면 해당 내용을 직접 복사해서 입력창에 붙여넣거나, 앱 내 코파일럿(Word, Excel 등)을 통해 현재 열린 파일을 분석하도록 요청해야 합니다.

**Q. 인터넷 없이도 코파일럿을 사용할 수 있나요?**

A. 아니요, 코파일럿은 마이크로소프트 서버와 통신하는 클라우드 기반 서비스이므로 인터넷 연결이 필요합니다.

**Q. 코파일럿 답변이 틀린 경우는 없나요?**

A. AI 서비스 특성상 답변이 부정확하거나 사실과 다를 수 있습니다. 중요한 정보는 반드시 공식 출처를 통해 교차 확인하는 것이 좋습니다. 코파일럿 답변 하단에는 참고한 출처 링크가 함께 표시되는 경우가 많으니 활용하세요.

**Q. 코파일럿 Pro와 무료 버전의 차이는 무엇인가요?**

A. 무료 버전은 기본적인 질문 응답, PC 설정 제어, 제한된 이미지 생성을 제공합니다. Copilot Pro(유료 구독)는 Microsoft 365 앱(Word, Excel 등) 내 코파일럿 기능, 더 많은 이미지 생성 크레딧, GPT-4 Turbo 우선 접근 등 추가 혜택을 제공합니다.

## 정리

윈도우 11 코파일럿은 단순한 검색 엔진을 넘어 PC 작업 전반을 도와주는 AI 어시스턴트입니다. 처음에는 간단한 질문과 PC 설정 제어부터 시작해 보고, 익숙해지면 문서 요약, 이미지 생성, 오피스 연동까지 활용 범위를 넓혀 보세요. `Windows 키 + C` 단축키를 기억해 두면 언제든 빠르게 코파일럿을 불러올 수 있습니다. AI 어시스턴트를 잘 활용하면 일상적인 PC 작업의 효율을 크게 높일 수 있습니다.
