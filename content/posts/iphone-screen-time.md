스마트폰 사용 시간이 걱정되시나요? 아이폰에는 **스크린 타임(Screen Time)** 이라는 기능이 내장되어 있어서 본인 또는 자녀의 앱 사용 시간을 세밀하게 관리할 수 있습니다. 특히 자녀의 아이폰을 부모가 원격으로 통제하거나, 본인 스스로 스마트폰 과의존을 줄이고 싶을 때 매우 유용합니다. 이 글에서는 스크린 타임의 모든 기능을 처음부터 차근차근 설명해 드립니다.

## 스크린 타임이란?

스크린 타임은 iOS 12부터 애플이 도입한 디지털 웰빙 기능입니다. 하루에 어떤 앱을 얼마나 사용했는지 통계를 보여주고, 특정 앱이나 카테고리의 사용 시간을 제한할 수 있습니다. 또한 취침 시간에는 알림을 차단하는 다운타임 기능, 앱 내 구매나 특정 콘텐츠를 제한하는 콘텐츠 및 개인 정보 보호 기능도 포함되어 있습니다.

부모라면 가족 공유 기능과 연동해 자녀의 기기를 원격에서 관리할 수 있어서, 게임 시간을 제한하거나 성인 콘텐츠를 차단하는 것이 가능합니다.

## 스크린 타임 켜는 방법

### 1단계: 설정 앱 열기

아이폰 홈 화면에서 회색 톱니바퀴 아이콘의 **설정(Settings)** 앱을 탭합니다.

### 2단계: 스크린 타임 메뉴 찾기

설정 화면을 아래로 스크롤하면 **스크린 타임** 항목이 보입니다. 탭해서 진입합니다.

### 3단계: 스크린 타임 켜기

"스크린 타임 켜기" 버튼을 탭합니다. 그러면 팝업 안내 화면이 뜨는데, "계속"을 탭합니다.

### 4단계: 사용 대상 선택

- **"이 기기가 나의 것입니다"** — 본인 아이폰을 관리할 때 선택
- **"이 기기가 내 자녀의 것입니다"** — 자녀 기기를 관리할 때 선택

자녀 기기를 선택하면 스크린 타임 암호를 설정하게 됩니다. 이 암호는 자녀가 제한을 풀지 못하도록 부모만 알아야 합니다. 기존에 사용하는 아이폰 잠금 암호와 다르게 설정하는 것을 권장합니다.

## 사용 시간 현황 확인하기

스크린 타임을 켜면 지난 24시간 또는 지난 7일간의 사용 통계를 볼 수 있습니다.

### 1단계: 스크린 타임 통계 화면 진입

설정 → 스크린 타임으로 들어가면 상단에 오늘 사용 시간 요약이 표시됩니다. "모두 보기"를 탭하면 상세 통계를 확인할 수 있습니다.

### 2단계: 앱별 사용 시간 확인

화면 상단의 그래프 아래에 카테고리별·앱별 사용 시간이 정렬됩니다. 소셜 네트워킹, 엔터테인먼트, 생산성 등 카테고리로 나뉘어 어디에 가장 많은 시간을 썼는지 한눈에 알 수 있습니다.

### 3단계: 주간 비교 확인

화면 상단의 "일" / "주" 탭을 전환하면 주간 평균 사용 시간과 지난주 대비 증감률을 확인할 수 있습니다. 특정 앱을 탭하면 해당 앱만의 일별 사용 통계도 볼 수 있습니다.

## 다운타임(Downtime) 설정 — 취침 시간 차단

다운타임은 지정한 시간 동안 선택한 앱만 사용할 수 있도록 제한하는 기능입니다. 예를 들어 밤 10시~아침 7시에는 전화와 카카오톡만 허용하고 나머지 앱은 모두 잠그는 방식으로 활용합니다.

### 1단계: 다운타임 메뉴 진입

설정 → 스크린 타임 → **다운타임**을 탭합니다.

### 2단계: 매일 또는 요일별 설정

- **매일** 토글을 켜면 동일한 시간으로 매일 적용됩니다.
- 요일별로 다르게 설정하려면 "매일" 토글을 끄고 각 요일을 개별 설정합니다. 예를 들어 주말에는 더 늦게까지 허용할 수 있습니다.

### 3단계: 시작/종료 시간 입력

시작 시간(예: 오후 10:00)과 종료 시간(예: 오전 7:00)을 설정합니다. 시간을 탭하면 스크롤 다이얼이 나타납니다.

### 4단계: 다운타임 중 허용할 앱 지정

다운타임 중에도 사용 가능한 앱을 "항상 허용"에서 추가할 수 있습니다 (아래 섹션 참조).

## 앱 시간 제한 설정

특정 앱이나 카테고리의 하루 최대 사용 시간을 정할 수 있습니다. 제한 시간이 다 되면 앱 아이콘에 모래시계 표시가 생기고 더 이상 실행되지 않습니다.

### 1단계: 앱 시간 제한 메뉴 진입

설정 → 스크린 타임 → **앱 시간 제한** → "제한 추가"를 탭합니다.

### 2단계: 제한할 앱/카테고리 선택

카테고리 목록(소셜 네트워킹, 게임, 엔터테인먼트 등)에서 선택하거나, 하단에 개별 앱을 검색해 선택합니다. 예를 들어 "게임"을 선택하면 모든 게임 앱에 동일한 제한이 적용됩니다.

### 3단계: 시간 설정

원하는 시간을 시(hour)와 분(minute) 단위로 설정합니다. 예를 들어 유튜브를 하루 1시간으로 제한하려면 "1시간 0분"으로 설정합니다.

### 4단계: 요일별 다른 시간 설정 (선택)

"요일 맞춤화"를 켜면 평일과 주말에 다른 제한 시간을 설정할 수 있습니다.

### 5단계: 추가 탭

오른쪽 상단의 "추가"를 탭하면 제한이 즉시 적용됩니다.

## 항상 허용 앱 설정

다운타임이나 앱 시간 제한 중에도 항상 사용할 수 있는 앱을 지정할 수 있습니다. 전화, 문자, 지도, 카메라 등 필수 앱은 여기에 추가해 두는 것이 좋습니다.

### 설정 방법

설정 → 스크린 타임 → **항상 허용**으로 들어갑니다. 기본적으로 전화 앱은 허용 목록에 있습니다. "+" 버튼을 탭해 카카오톡, 문자 등 필수 앱을 추가합니다.

## 콘텐츠 및 개인 정보 보호 제한

자녀의 기기에서 성인 콘텐츠, 앱 설치/삭제, 개인정보 변경 등을 차단하는 기능입니다.

### 1단계: 메뉴 진입 및 활성화

설정 → 스크린 타임 → **콘텐츠 및 개인 정보 보호 제한**을 탭하고 상단 토글을 켭니다.

### 2단계: iTunes 및 App Store 구매 제한

"iTunes 및 App Store 구매" 항목에서 앱 설치, 앱 삭제, 인앱 구매 각각을 "허용 안 함"으로 설정할 수 있습니다. 자녀가 부모 동의 없이 앱을 설치하거나 결제하는 것을 막을 때 유용합니다.

### 3단계: 콘텐츠 제한 설정

"콘텐츠 제한"을 탭하면 다음 항목들을 세부 설정할 수 있습니다:
- **앱**: 연령대별 허용 (4+, 9+, 12+, 17+, 전체 허용)
- **웹 콘텐츠**: 성인 웹사이트 제한, 허용된 웹사이트만 접속
- **Siri**: 성인 언어 및 성인 웹 검색 제한
- **음악/팟캐스트/뉴스**: 명시적 콘텐츠 허용 여부

### 4단계: 개인 정보 보호 잠금

"개인 정보 보호" 항목에서 위치 서비스, 연락처, 마이크 등의 앱 접근 권한을 변경하지 못하도록 잠글 수 있습니다.

## 스크린 타임 암호 설정 및 변경

스크린 타임의 모든 제한은 암호로 보호됩니다. 자녀가 제한을 임의로 해제하지 못하도록 반드시 설정하세요.

### 암호 설정 방법

설정 → 스크린 타임 → **스크린 타임 암호 사용**을 탭하고 4자리 암호를 입력합니다. 암호를 잊어버렸을 때를 대비해 Apple ID로 복구하는 옵션도 함께 설정하는 것을 권장합니다.

### 암호 변경/해제

설정 → 스크린 타임 → "스크린 타임 암호 변경" 또는 "스크린 타임 암호 끄기"를 탭한 후 기존 암호를 입력합니다.

## 가족 공유로 자녀 기기 원격 관리

자녀 아이폰을 직접 들고 있지 않아도 부모 아이폰에서 원격으로 스크린 타임을 관리할 수 있습니다.

### 1단계: 가족 공유 설정

부모 아이폰의 설정 → [이름] → **가족 공유** → "가족 구성원 추가"에서 자녀의 Apple ID를 추가합니다. 자녀가 13세 미만이라면 "어린이 계정 만들기"로 자녀 Apple ID를 생성합니다.

### 2단계: 자녀 기기에서 스크린 타임 활성화

자녀 아이폰의 설정 → 스크린 타임에서 스크린 타임을 켜고 "이 기기가 내 자녀의 것입니다"를 선택합니다.

### 3단계: 부모 기기에서 원격 관리

부모 아이폰의 설정 → 스크린 타임에서 가족 구성원 목록에 자녀 이름이 보입니다. 자녀 이름을 탭하면 자녀의 사용 통계와 모든 스크린 타임 설정을 부모 기기에서 직접 변경할 수 있습니다.

## 자주 묻는 질문 (Q&A)

**Q. 스크린 타임 암호를 잊어버렸어요. 어떻게 하나요?**
A. iOS 설정 앱 → 스크린 타임 → 암호 끄기/변경 시 "Apple ID로 재설정"을 탭합니다. Apple ID 이메일과 비밀번호를 입력하면 새 암호를 설정할 수 있습니다. Apple ID 연동 없이 잊어버렸다면 아이폰을 초기화해야 할 수 있으니 꼭 연동해 두세요.

**Q. 시간 제한이 다 됐는데 자녀가 "1분 더" 요청을 계속 보내요.**
A. 앱 시간 제한 설정에서 "시간 종료 시 차단"을 완전히 적용하려면 스크린 타임 암호를 반드시 설정해야 합니다. 암호가 없으면 자녀가 쉽게 제한을 무시하고 연장할 수 있습니다.

**Q. 특정 앱은 제한하고 싶지 않아요. 예외 설정이 가능한가요?**
A. 카테고리 전체를 제한하더라도 "항상 허용" 목록에 앱을 추가하면 제한 없이 사용할 수 있습니다.

**Q. 스크린 타임을 완전히 끄면 모든 데이터가 사라지나요?**
A. 스크린 타임을 끄면 그동안 쌓인 사용 통계는 삭제됩니다. 다시 켜면 그 시점부터 새로 데이터가 쌓입니다.

**Q. 아이패드와 아이폰을 같이 쓰는데, 두 기기를 동시에 관리할 수 있나요?**
A. 가족 공유로 연결된 기기라면 각 기기별로 별도 스크린 타임이 적용됩니다. 기기마다 설정을 따로 해주어야 하지만, 사용 통계는 부모 기기에서 각 기기별로 확인할 수 있습니다.

## 정리

아이폰 스크린 타임은 단순한 사용 통계를 넘어 디지털 생활 전반을 건강하게 관리할 수 있는 강력한 도구입니다. 핵심 기능을 요약하면 다음과 같습니다.

| 기능 | 용도 |
|------|------|
| 사용 현황 | 앱별·카테고리별 사용 시간 확인 |
| 다운타임 | 특정 시간대 앱 사용 차단 |
| 앱 시간 제한 | 하루 최대 사용 시간 설정 |
| 항상 허용 | 제한 중에도 사용 가능한 앱 지정 |
| 콘텐츠 제한 | 성인 콘텐츠·앱 구매 차단 |
| 가족 공유 | 부모 기기에서 자녀 기기 원격 관리 |

처음에는 복잡해 보일 수 있지만, 한 번 설정해두면 매일 자동으로 작동하므로 스마트폰 사용 습관을 개선하는 데 큰 도움이 됩니다. 특히 초등학생·중학생 자녀가 있는 부모라면 꼭 활용해 보시기 바랍니다.
