## 올리브영 앱이란?

올리브영은 국내 최대 H&B(헬스앤뷰티) 스토어로, 앱을 통해 전국 1,300여 개 매장 상품을 온라인으로 구매할 수 있어요. 특히 **오늘드림** 서비스는 주문 후 3시간 이내에 배송해주는 빠른 배송 서비스로 많은 분들이 이용하고 있어요.

올리브영 앱의 주요 특징을 먼저 살펴볼게요:

- **오늘드림**: 오후 11시 전 주문 시 당일 배송 (일부 지역)
- **픽업 서비스**: 온라인 주문 후 가까운 매장에서 직접 수령
- **올영세일**: 연 2회 최대 50% 할인 행사
- **멤버십**: 구매금액에 따라 일반/골드/플래티넘/VIP 등급으로 혜택 제공
- **올리브포인트**: 구매 시 적립하고 다음 결제 때 사용 가능

매장에 직접 가기 어려운 분들에게 올리브영 앱은 매우 편리한 대안이에요. 화장품, 스킨케어, 건강식품, 생활용품까지 다양한 카테고리를 한 곳에서 쇼핑할 수 있어요.

## 올리브영 앱 설치 및 회원가입

### 앱 설치

1. 아이폰 사용자는 **앱스토어**, 갤럭시/안드로이드 사용자는 **구글플레이스토어** 실행
2. 검색창에 **올리브영** 입력
3. 공식 앱 선택 후 **설치** 클릭
4. 설치 완료 후 앱 실행

### 회원가입 방법

1. 앱 하단 **마이** 탭 클릭
2. **로그인/회원가입** 버튼 클릭
3. **이메일로 가입하기** 또는 SNS 간편 가입 선택

**이메일 가입 순서**:
1. 이메일 주소 입력
2. 비밀번호 설정 (영문+숫자+특수문자 조합, 8~20자)
3. 이름, 생년월일 입력
4. 휴대폰 번호 입력 후 인증번호 확인
5. 마케팅 수신 동의 여부 선택 (선택 사항)
6. **가입 완료** 클릭

**팁**: 카카오, 네이버, 애플 계정으로 간편 로그인도 가능해요. 별도의 비밀번호를 기억하기 어렵다면 SNS 계정 연동을 추천해요. 단, SNS 탈퇴 시 올리브영 계정 접근이 어려울 수 있으니 참고하세요.

## 상품 검색 및 구매하기

### 원하는 상품 찾기

1. 앱 하단 **돋보기(검색) 아이콘** 클릭
2. 검색창에 상품명, 브랜드명 입력 (예: "선크림", "라네즈", "비타민C 세럼")
3. 검색 결과에서 원하는 상품 클릭
4. 상세 페이지에서 성분, 사용법, 실제 구매자 **리뷰** 꼼꼼히 확인

**카테고리별 탐색 방법**:
- 홈 화면 상단의 **카테고리** 탭에서 스킨케어, 메이크업, 바디, 헤어, 건강식품 등 선택
- **랭킹** 탭에서 전체 인기 상품, 카테고리별 인기 상품 순위 실시간 확인
- **기획전** 탭에서 현재 진행 중인 할인 이벤트 확인

### 장바구니에 담기 및 결제하기

1. 상품 상세 페이지에서 **장바구니 담기** 또는 **바로구매** 클릭
2. 용량, 색상, 향 등 옵션 선택 (해당하는 경우)
3. 수량 선택 후 **확인** 클릭
4. 장바구니 화면에서 구매할 상품 최종 확인
5. **주문하기** 클릭
6. 배송지 주소 입력 또는 기존 저장 주소 선택
7. 결제 방법 선택: 신용/체크카드, 카카오페이, 네이버페이, 토스, 계좌이체 등
8. 보유 쿠폰, 올리브포인트 적용 (있는 경우)
9. 최종 금액 확인 후 **결제하기** 클릭

**팁**: 첫 구매 시 나타나는 신규 회원 쿠폰을 꼭 적용하세요. 보통 10~20% 할인 또는 일정 금액 할인 쿠폰이 제공돼요.

## 오늘드림 서비스 이용하기

오늘드림은 올리브영 앱의 핵심 서비스로, 가까운 올리브영 매장에서 직접 픽업해 배송해주는 초고속 배송 서비스예요.

### 오늘드림 주문 방법

1. 상품 페이지에서 **오늘드림 가능** 배지 확인
2. 장바구니에 담고 결제 화면으로 이동
3. 배송 방법에서 **오늘드림** 선택
4. 배송지 주소 입력 (현재 위치 또는 원하는 주소)
5. 배송 가능 예상 시간 확인 (보통 2~3시간 이내)
6. 결제 완료 후 앱에서 실시간 배송 현황 추적 가능

### 오늘드림 이용 조건 및 정책

| 항목 | 내용 |
|---|---|
| 최소 주문 금액 | 15,000원 이상 |
| 배송비 | 3,000원 (35,000원 이상 무료) |
| 이용 가능 시간 | 오전 10시 ~ 오후 11시 |
| 서비스 지역 | 전국 대부분 (도서산간 일부 제외) |

**팁**: 오늘드림 가능 여부는 배송지 주소에 따라 달라져요. 지역 내 재고가 있어야 하기 때문에 인기 상품의 경우 오늘드림이 불가한 경우도 있어요. 이럴 때는 다음날 일반 배송이나 매장 픽업을 이용하세요.

## 매장 픽업 서비스 이용하기

온라인으로 주문하고 가까운 올리브영 매장을 방문해 직접 수령하는 방법이에요. 배송비를 아끼고 싶거나 외출 중에 들러서 받고 싶을 때 유용해요.

1. 상품 페이지에서 **매장 픽업** 선택
2. **내 주변 매장 찾기** 클릭
3. 현재 위치 또는 원하는 지역 검색
4. 해당 매장의 재고 확인 후 **픽업 신청** 클릭
5. 결제 완료
6. 준비 완료 문자 수신 후 매장 방문 (보통 1~2시간 내 준비 완료)
7. 매장 직원에게 **주문 번호** 또는 앱의 **QR코드** 제시 후 수령

**장점**: 배송비 절약은 물론, 원하는 시간에 픽업할 수 있어서 재택근무자나 외출이 잦은 분들에게 편리해요.

## 멤버십 등급 및 혜택

올리브영 멤버십은 연간 구매 금액에 따라 등급이 나뉘어요.

| 등급 | 연간 구매금액 | 주요 혜택 |
|---|---|---|
| 일반 | 0원 이상 | 기본 포인트 적립 (1%) |
| 골드 | 50만원 이상 | 생일 쿠폰, 전용 할인 쿠폰 |
| 플래티넘 | 150만원 이상 | 전용 쿠폰, VIP 전용 이벤트 초대 |
| VIP | 300만원 이상 | 전 상품 추가 할인, 무료 배송 혜택 |

**올리브포인트 적립 및 사용**:
- 구매 금액의 1~5% 적립 (등급에 따라 다름)
- 1포인트 = 1원으로 결제 시 사용 가능
- 최소 사용 금액: 1,000포인트 이상 (일부 상품 제외)
- 포인트 유효기간: 마지막 구매일로부터 1년

**팁**: 회원 등급은 매년 1월에 전년도 구매 실적으로 재산정돼요. 연말에 구매를 몰아서 하면 등급 유지나 승급에 도움이 돼요.

## 쿠폰 및 할인 혜택 받기

### 보유 쿠폰 확인 및 사용

1. 앱 하단 **마이** 탭 클릭
2. **쿠폰** 메뉴에서 현재 보유한 쿠폰 목록 확인
3. **쿠폰함** → **다운로드 가능 쿠폰** 탭에서 추가 쿠폰 다운로드
4. 결제 화면에서 **쿠폰 적용** 선택 후 원하는 쿠폰 체크

### 정기 세일 및 이벤트

- **올영세일**: 연 2회 진행 (보통 봄·가을), 최대 50% 할인
- **올데이세일**: 브랜드별 특가 이벤트
- **생일 할인**: 생일 달에 추가 쿠폰 제공 (골드 이상 등급)
- **앱 전용 할인**: 앱에서만 제공되는 단독 쿠폰

**팁**: 올영세일 기간에는 인기 상품이 품절되기 쉬워요. 장바구니에 미리 담아두었다가 세일 시작 직후 빠르게 결제하는 것을 추천해요.

## 반품 및 교환 방법

### 반품/교환 신청

1. 앱 → **마이** 탭 → **주문 내역** 클릭
2. 해당 주문 클릭
3. **반품/교환 신청** 클릭
4. 사유 선택 (단순 변심 / 상품 불량 / 오배송 등)
5. 신청 완료 후 수거 일정 문자 수신

### 반품 정책 요약

- 수령 후 **7일 이내** 신청 가능
- **단순 변심**: 왕복 배송비 6,000원 고객 부담
- **상품 불량·오배송**: 무료 반품 처리
- 개봉·사용한 제품은 반품 불가 (단, 불량인 경우 예외)

## 자주 묻는 질문

**Q. 오늘드림 배송이 안 된다고 나오는데 왜 그런가요?**
배송지 주소가 서비스 지역 밖이거나, 해당 상품의 근처 매장 재고가 부족한 경우, 또는 주문 마감 시간(오후 11시)이 지난 경우예요. 다음날 일반 배송을 이용하거나 매장 픽업으로 대체하세요.

**Q. 올리브포인트는 언제 소멸되나요?**
마지막 구매일로부터 1년 후 소멸돼요. 앱 마이페이지의 **포인트** 메뉴에서 유효기간을 확인할 수 있어요. 잊지 않도록 유효기간 임박 알림을 설정해 두세요.

**Q. 앱에서 오프라인 매장 재고를 확인할 수 있나요?**
네. 상품 페이지 하단의 **매장 재고 확인** 버튼을 클릭하면 근처 매장별 재고 현황을 확인할 수 있어요. 품절된 온라인 상품도 매장에는 재고가 있을 수 있으니 활용해보세요.

**Q. 선물 포장 서비스가 있나요?**
네. 일부 상품은 결제 시 선물 포장 옵션을 선택할 수 있어요. 선물 발송 시 메시지 카드도 함께 동봉할 수 있어요.

**Q. 영수증 없이도 교환이 가능한가요?**
앱에서 구매한 경우 주문 내역이 자동으로 저장되기 때문에 별도의 영수증 없이도 앱 주문 내역을 통해 교환·반품 신청이 가능해요.

## 요약

올리브영 앱은 화장품, 건강식품, 생활용품을 편리하게 구매할 수 있는 쇼핑 앱이에요. 핵심 기능은 **오늘드림**(당일 3시간 이내 배송), **매장 픽업**(배송비 절약), **멤버십**(포인트 적립 및 쿠폰)이에요. 올영세일 기간에 구매하면 최대 50%까지 할인받을 수 있으니 세일 일정을 앱 알림으로 미리 체크해 두면 좋아요. 회원가입 후 신규 쿠폰도 챙기는 것 잊지 마세요!
