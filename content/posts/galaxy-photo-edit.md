## 갤럭시 갤러리 편집 기능, 이렇게 좋은 줄 몰랐죠?

갤럭시 스마트폰에는 별도의 편집 앱 없이도 사진을 멋지게 꾸밀 수 있는 강력한 갤러리 편집 기능이 내장되어 있어요. 밝기, 색감 조절은 물론이고 AI 기반 객체 지우기, 리마스터, 사진 내 텍스트 추출까지 가능합니다. 삼성 갤럭시 S24 시리즈 이후로는 Galaxy AI 기능이 더해져서 편집 수준이 크게 높아졌어요.

이 글에서는 갤럭시 갤러리 앱의 편집 기능을 처음부터 끝까지 차근차근 설명해 드릴게요.

## 편집 화면 진입하는 방법

1. **갤러리 앱**을 실행하세요.
2. 편집하고 싶은 **사진을 탭**해서 전체 화면으로 엽니다.
3. 하단 중앙에 있는 **연필(✏️) 아이콘**을 탭하면 편집 화면으로 들어갑니다.
   - 아이콘이 보이지 않으면 화면을 한 번 탭해서 도구 모음을 불러오세요.
4. 편집 화면 하단에 여러 편집 도구가 나타납니다.

> 💡 원본 사진은 따로 저장되어 있어서 편집 후 저장해도 원본이 사라지지 않아요. 언제든지 **원본으로 되돌리기**가 가능합니다.

## 기본 편집: 밝기, 색감, 선명도 조절

가장 많이 쓰는 기본 편집 기능부터 익혀봐요.

1. 편집 화면 하단에서 **조정(슬라이더 아이콘)** 탭을 선택하세요.
2. 화면에 다음과 같은 슬라이더들이 나타납니다:
   - **밝기**: 사진 전체를 밝거나 어둡게 조절
   - **노출**: 빛의 노출량 조절 (밝기와 유사하지만 더 세밀하게 제어 가능)
   - **대비**: 밝은 부분과 어두운 부분의 차이를 강조
   - **하이라이트**: 밝은 영역만 조절
   - **그림자**: 어두운 영역만 조절
   - **채도**: 색상의 선명도 조절
   - **색조**: 색상의 따뜻하고 차가운 느낌 조절
   - **선명도**: 사진의 윤곽선을 더 뚜렷하게
3. 원하는 항목을 탭한 후 **슬라이더를 좌우로 드래그**해서 값을 조절해요.
4. 맘에 들면 **저장** 또는 **복사본으로 저장**을 탭하세요.

**꿀팁**: 실내에서 찍은 어두운 사진은 밝기 +30, 그림자 +20 정도만 올려도 훨씬 선명해져요.

## 필터로 분위기 바꾸기

1. 편집 화면 하단에서 **필터(동그라미 아이콘)** 탭을 선택하세요.
2. 화면 하단에 다양한 필터 프리셋이 나열돼요:
   - **원본**: 편집 전 상태
   - **선명함**, **생동감**, **따뜻함**, **차가움** 등 다양한 분위기
3. 원하는 필터를 탭하면 미리보기가 즉시 적용됩니다.
4. 필터를 다시 탭하면 **강도 슬라이더**가 나타나서 0~100 사이로 세기를 조절할 수 있어요.
5. 원하는 결과가 나오면 **저장**을 탭하세요.

## 자르기 & 회전 기능

1. 편집 화면 하단에서 **변환(화살표 아이콘)** 탭을 선택하세요.
2. 다음 기능들을 사용할 수 있어요:
   - **자르기**: 화면 모서리의 핸들을 드래그해서 원하는 영역만 남기기
   - **비율 고정**: 1:1 (인스타그램용), 4:3, 16:9 등 비율 고정 후 자르기
   - **회전**: 오른쪽으로 90도씩 회전
   - **뒤집기**: 좌우 또는 상하 반전
   - **수평 맞추기**: 약간 기울어진 사진을 수평으로 자동 보정

**자르기 활용 예시**:
- 인스타그램 게시물: **1:1** 비율로 자르기
- 유튜브 썸네일: **16:9** 비율로 자르기
- 증명사진 자르기: **3:4** 비율 사용

## Galaxy AI: 객체 지우기 & 이동

One UI 6.1 이상 갤럭시 기기에서는 AI 기반 편집 기능을 쓸 수 있어요.

**객체 지우기 방법**:
1. 편집 화면 하단에서 **Galaxy AI(별 모양 아이콘)** 탭을 선택하세요.
2. **객체 지우기**를 탭하세요.
3. 지우고 싶은 사람이나 물체를 **손가락으로 원을 그려서 선택**하거나, 자동으로 감지된 객체를 탭하세요.
4. **지우기** 버튼을 누르면 AI가 주변 배경을 분석해서 해당 부분을 자연스럽게 채워줍니다.
5. 결과를 확인하고 마음에 들면 **저장**하세요.

**객체 이동 방법**:
1. **Galaxy AI → 객체 이동**을 선택하세요.
2. 이동할 객체를 선택한 후 **원하는 위치로 드래그**하세요.
3. AI가 원래 자리와 이동한 자리 모두 자연스럽게 처리해줍니다.

> ⚠️ 복잡한 배경에서는 결과가 완벽하지 않을 수 있어요. 필요하면 여러 번 시도해보세요.

## Galaxy AI: 사진 리마스터

오래된 사진이나 화질이 낮은 사진을 AI로 향상시키는 기능이에요.

1. 편집 화면에서 **Galaxy AI → 리마스터**를 선택하세요.
2. AI가 자동으로 사진의 화질, 색상, 선명도를 개선합니다.
3. 원본과 비교해서 더 나은 버전을 선택해 저장하세요.

특히 오래된 가족사진이나 화질이 낮은 사진을 인쇄해야 할 때 매우 유용해요.

## 스티커 & 텍스트 추가하기

1. 편집 화면 하단에서 **꾸미기(스마일 아이콘)** 탭을 선택하세요.
2. 다음 기능을 활용할 수 있어요:
   - **스티커**: 이모지, 카카오프렌즈 등 다양한 스티커 추가
   - **텍스트**: 글씨를 입력하고 폰트, 색상, 크기 조절
   - **그리기**: 손으로 직접 그림 그리기 (펜 색상, 굵기 선택 가능)
3. 원하는 요소를 추가한 후 위치를 이동하거나 크기를 조절해 주세요.
4. **저장** 또는 **복사본으로 저장**으로 마무리하세요.

## 사진 내 텍스트 추출 기능

사진에 찍힌 텍스트를 복사해서 쓸 수 있어요.

1. 갤러리에서 텍스트가 포함된 사진을 여세요.
2. 하단의 **T (텍스트 추출)** 아이콘을 탭하세요.
   - 없으면 **더 보기(···)** 탭에서 **텍스트 추출** 선택
3. AI가 사진 속 텍스트를 인식하고 선택 가능한 형태로 보여줍니다.
4. 원하는 텍스트를 **길게 눌러서 복사**하거나 전체 선택 후 복사하세요.

**활용 사례**:
- 명함 사진에서 전화번호, 이메일 복사하기
- 영수증 사진에서 금액 복사하기
- 칠판/화이트보드 사진에서 내용 복사하기

## 편집 후 공유 및 저장 방법

1. 편집이 완료되면 우측 상단 **저장** 버튼을 탭하세요.
2. 두 가지 저장 옵션이 있어요:
   - **저장**: 편집된 사진이 원본을 대체해요 (원본은 별도 보관됨)
   - **복사본으로 저장**: 원본은 그대로 두고 편집본을 새로 저장
3. SNS에 바로 공유하려면 우측 상단 **공유 버튼**을 탭하세요.

## 자주 묻는 질문 (Q&A)

**Q. 편집한 사진을 원본으로 되돌리는 방법은?**
갤러리에서 편집한 사진을 열고 우측 상단 **더 보기(···) → 원본으로 되돌리기**를 선택하면 처음 상태로 완전히 복원돼요. 단, 복사본으로 저장한 경우에는 해당되지 않아요.

**Q. 갤럭시 AI 기능이 보이지 않아요.**
Galaxy AI는 One UI 6.1 이상 + 갤럭시 S23 이상(또는 지원 기기)에서 사용 가능해요. 기기와 소프트웨어를 최신 버전으로 업데이트해 보세요.

**Q. 여러 사진을 한 번에 편집할 수 있나요?**
갤러리 기본 편집 기능은 사진 하나씩 편집해야 해요. 여러 사진에 동일한 필터를 적용하려면 캡컷(CapCut) 같은 별도 앱을 활용해 보세요.

**Q. 편집 중 실수한 건 되돌릴 수 있나요?**
편집 화면 상단의 **←(실행 취소)** 버튼을 탭하면 이전 단계로 돌아갈 수 있어요. 저장하기 전까지는 자유롭게 실행 취소가 가능합니다.

**Q. 사진 용량이 너무 클 때 줄이는 방법은?**
편집 화면에서 **더 보기(···) → 크기 조절**을 탭하면 사진의 해상도를 낮춰서 파일 크기를 줄일 수 있어요.

## 정리

갤럭시 갤러리 앱의 편집 기능은 생각보다 훨씬 강력합니다. 별도의 앱 설치 없이도 기본 색감 보정부터 AI 객체 지우기, 리마스터, 텍스트 추출까지 가능해요.

| 기능 | 위치 |
|---|---|
| 밝기/색감 조절 | 조정 탭 (슬라이더 아이콘) |
| 필터 적용 | 필터 탭 (동그라미 아이콘) |
| 자르기/회전 | 변환 탭 (화살표 아이콘) |
| AI 객체 지우기/이동 | Galaxy AI 탭 (별 아이콘) |
| 스티커/텍스트 | 꾸미기 탭 (스마일 아이콘) |
| 텍스트 추출 | 더 보기 → 텍스트 추출 |

오늘 바로 갤러리 앱에서 사진 하나를 열어서 편집해 보세요! 생각보다 쉽고 결과도 놀라울 거예요.
