## 마이크로소프트 엣지란?

마이크로소프트 엣지(Microsoft Edge)는 윈도우 11에 기본으로 탑재된 공식 웹 브라우저예요. 과거에 사용하던 인터넷 익스플로러(Internet Explorer)를 완전히 대체했으며, 구글 크롬과 동일한 Chromium 엔진을 기반으로 만들어져 대부분의 웹사이트에서 호환이 잘 돼요.

많은 분들이 크롬이나 네이버 웨일 등 다른 브라우저를 따로 설치해서 사용하는데, 엣지에도 편리한 기능이 많아요. 기본 브라우저인 만큼 윈도우와 가장 잘 통합되어 있어 활용해볼 만해요.

**엣지의 주요 장점**:
- 윈도우에 최적화 → 크롬보다 배터리 소모가 적음 (노트북 사용자에게 유리)
- **코파일럿(Copilot) AI** 기능 탑재 → 검색, 요약, 번역 지원
- **절전 탭** 기능 → 메모리 절약으로 PC 속도 개선
- Microsoft 365, OneDrive와 자연스러운 연동
- 크롬 확장 프로그램 설치 호환 가능
- 내장 PDF 뷰어 및 편집 기능

## 엣지 브라우저 기본 설정

### 시작 페이지 설정

엣지를 처음 실행하면 뉴스와 날씨가 가득한 기본 페이지가 열려요. 원하는 페이지로 바꾸는 방법이에요.

1. 엣지 오른쪽 상단 **점 세 개(···)** 버튼 클릭
2. **설정** 클릭
3. 왼쪽 메뉴에서 **시작, 홈 및 새 탭** 클릭
4. **Microsoft Edge 시작 시** 항목에서 원하는 옵션 선택:
   - **새 탭 페이지 열기**: 뉴스·날씨·빠른 링크가 있는 기본 화면
   - **이전 세션의 탭 열기**: 마지막에 보던 사이트들을 그대로 유지
   - **특정 페이지 또는 페이지 열기**: 원하는 주소 직접 입력 (예: naver.com)

**팁**: 매번 네이버나 카카오로 시작하고 싶다면 **특정 페이지 열기**를 선택하고 원하는 주소를 입력하세요.

### 기본 검색 엔진 변경 (Bing → 구글/네이버)

엣지의 기본 검색 엔진은 마이크로소프트의 Bing이에요. 구글이나 네이버로 바꾸려면:

1. **설정** → **개인 정보, 검색 및 서비스** 클릭
2. 아래로 스크롤하여 **주소 표시줄 및 검색** 클릭
3. **주소 표시줄에 사용된 검색 엔진** 드롭다운에서 **Google** 또는 **Naver** 선택

이제 주소창에 검색어를 입력하면 선택한 검색 엔진으로 검색돼요.

## 즐겨찾기(북마크) 완벽 활용

### 즐겨찾기 추가하기

1. 자주 방문하는 사이트 접속
2. 주소창 오른쪽 끝 **별 모양 아이콘(☆)** 클릭 또는 **Ctrl + D** 단축키
3. 이름 수정 (필요한 경우)
4. 저장할 폴더 선택 (즐겨찾기 모음, 기타 즐겨찾기 또는 직접 만든 폴더)
5. **완료** 클릭

### 즐겨찾기 모음 항상 표시

1. **설정** → **모양** 클릭
2. **즐겨찾기 모음 표시** 항목에서 **항상** 선택

이제 모든 페이지 상단에 즐겨찾기 모음이 표시돼 자주 가는 사이트를 한 번에 접속할 수 있어요.

### 즐겨찾기 폴더로 정리하기

1. 즐겨찾기 모음에서 빈 공간 **오른쪽 클릭**
2. **새 폴더 추가** 클릭
3. 폴더 이름 입력 (예: 뉴스, 쇼핑, 은행 등)
4. 드래그앤드롭으로 즐겨찾기를 각 폴더로 이동

### 다른 기기와 즐겨찾기 동기화

Microsoft 계정으로 로그인하면 집 PC, 직장 PC, 스마트폰에서 같은 즐겨찾기와 비밀번호를 사용할 수 있어요.

1. 오른쪽 상단 **프로필 아이콘** 클릭
2. **Microsoft 계정으로 로그인** 클릭
3. 마이크로소프트 계정(이메일) 및 비밀번호 입력
4. 로그인 완료 후 **동기화 설정** → 동기화할 항목(즐겨찾기, 비밀번호, 방문 기록 등) 선택

**팁**: 회사 PC와 집 PC에서 같은 계정으로 로그인하면 즐겨찾기가 자동으로 공유돼요. 새 PC로 교체해도 즐겨찾기를 다시 설정할 필요가 없어요.

## AI 코파일럿(Copilot) 활용하기

엣지에는 마이크로소프트의 AI 코파일럿이 내장돼 있어요. 인터넷 검색 기반으로 최신 정보를 반영하며, 요약·번역·질문 답변 등 다양하게 활용할 수 있어요.

### 코파일럿 실행 방법

- 오른쪽 상단 **코파일럿 아이콘** 클릭 (사람 모양에 별 표시)
- 또는 단축키 `Ctrl + Shift + .` (마침표)

### 웹페이지 요약 기능

뉴스 기사나 긴 글을 읽을 시간이 없을 때 유용해요.

1. 요약하고 싶은 기사나 페이지 열기
2. 코파일럿 패널 열기
3. **이 페이지에 대해 묻기** 클릭 또는 직접 질문 입력: "이 기사를 3줄로 요약해줘"
4. AI가 즉시 요약 제공

### 번역 기능

1. 영어, 일본어 등 외국어 사이트 접속
2. 코파일럿에 "이 페이지를 한국어로 번역해줘" 입력
3. 주요 내용을 한국어로 설명해줌

**내장 번역 기능도 있어요**: 외국어 페이지 접속 시 주소창 오른쪽에 **번역 아이콘**이 자동으로 나타나요. 클릭하면 페이지 전체를 한국어로 번역해요.

### 쇼핑 도우미로 활용

1. 쿠팡, G마켓 등 쇼핑 사이트에서 상품 페이지 열기
2. 코파일럿에 "이 상품 리뷰를 요약해줘" 또는 "비슷한 상품과 비교해줘" 입력
3. AI가 리뷰 요약, 가격 비교 등 정보 제공

## 절전 탭 기능으로 PC 속도 향상

탭을 10개, 20개씩 열어두면 RAM이 부족해져 PC가 느려져요. 엣지의 **절전 탭** 기능은 일정 시간 사용하지 않은 탭을 자동으로 절전 상태로 전환해 메모리를 크게 절약해요.

### 절전 탭 설정 방법

1. **설정** 클릭
2. **시스템 및 성능** 메뉴 클릭
3. **절전 탭으로 성능 향상** 토글을 **켜기** 상태로 변경
4. 절전 상태로 전환할 유휴 시간 설정 (예: 5분, 15분, 30분 등)

### 절전 탭 확인

- 절전 상태가 된 탭에는 탭 이름 옆에 **리프(나뭇잎) 아이콘**이 표시돼요
- 해당 탭을 클릭하면 즉시 다시 로드돼요
- 탭을 많이 열어두는 분이라면 메모리 사용량이 수백 MB~1GB 이상 줄어들 수 있어요

**팁**: 평소 탭을 20개 이상 열어두고 사용하는 분이라면 절전 탭 기능만으로도 PC 체감 속도가 크게 향상돼요.

## 세로 탭 사용하기

탭이 많아지면 각 탭 이름이 보이지 않아 원하는 탭을 찾기 어려워요. **세로 탭** 기능을 사용하면 탭이 화면 왼쪽에 목록 형태로 표시되어 관리가 훨씬 편해요.

### 세로 탭 활성화

1. 화면 왼쪽 상단의 **세로 탭 전환 아이콘** 클릭
2. 또는 **설정** → **모양** → **세로 탭 표시** 켜기

세로 탭 모드에서는 각 탭의 사이트 이름 전체가 보이고, 파비콘(사이트 아이콘)도 함께 표시돼 어떤 탭인지 한눈에 파악할 수 있어요.

## 비밀 브라우징 (InPrivate 모드)

방문 기록, 쿠키, 로그인 정보, 검색 기록을 저장하지 않는 모드예요.

### 실행 방법

- 단축키 `Ctrl + Shift + N`
- 또는 **점 세 개(···)** → **새 InPrivate 창**

### 활용 예시

- 공용 PC(도서관, 카페)에서 사용 후 흔적 남기지 않기
- 하나의 사이트에 두 계정으로 동시에 로그인할 때
- 항공권, 호텔 가격 비교 시 (쿠키 기반 가격 추적 방지 효과)

**주의**: InPrivate 모드를 써도 인터넷 공급자(KT, SK, LG U+), 학교/회사 네트워크에서는 어떤 사이트를 방문했는지 기록이 남을 수 있어요. 완전한 익명성을 보장하지는 않아요.

## 내장 PDF 뷰어 및 편집

별도 프로그램 없이 PDF 파일을 열고 간단히 편집하는 방법이에요.

1. PDF 파일에서 마우스 오른쪽 클릭 → **프로그램으로 열기** → **Microsoft Edge**
2. 상단 도구 모음에서 다양한 작업 선택:
   - **그리기**: 펜으로 직접 메모나 서명 추가
   - **텍스트 강조**: 중요 내용에 형광펜 표시
   - **텍스트 추가**: 빈 공간에 텍스트 입력
   - **읽기 소리내어 읽기**: AI가 텍스트를 음성으로 읽어줌 (속도 조절 가능)
3. 편집 후 **저장** 또는 **다른 이름으로 저장** 클릭

**팁**: 계약서나 신청서 PDF에 직접 서명 또는 메모를 추가하고 싶을 때 유용해요. 어도비 아크로뱃 같은 유료 프로그램 없이도 기본 편집이 가능해요.

## 자주 묻는 질문

**Q. 크롬 확장 프로그램을 엣지에서도 사용할 수 있나요?**
네. 크롬 웹 스토어에서 엣지로 접속하면 "다른 스토어의 확장 허용" 메시지가 나와요. 허용하면 크롬 전용 확장 프로그램도 엣지에 설치할 수 있어요. 광고 차단기(uBlock Origin), 번역 프로그램 등 크롬에서 쓰던 확장이 대부분 호환돼요.

**Q. 인터넷뱅킹이나 공공기관 사이트가 엣지에서 안 열려요.**
일부 오래된 공공기관·금융 사이트는 인터넷 익스플로러(IE) 환경에서만 작동해요. 이런 경우 **설정** → **기본 브라우저** → **Internet Explorer 호환성** → **Internet Explorer 모드에서 사이트 열기** 허용 → 해당 사이트 주소 추가하면 해결돼요.

**Q. 엣지가 너무 느려요. 어떻게 하면 좋을까요?**
확장 프로그램을 많이 설치하면 브라우저가 느려질 수 있어요. **점 세 개** → **확장** 메뉴에서 사용하지 않는 확장 프로그램을 비활성화하거나 삭제해보세요. 또한 **설정** → **시스템 및 성능** → **시작 부스트** 기능을 켜면 엣지 실행 속도가 빨라져요.

**Q. 저장된 비밀번호는 어디서 확인하나요?**
**설정** → **비밀번호** 메뉴에서 엣지에 저장된 모든 비밀번호를 확인, 수정, 삭제할 수 있어요. Microsoft 계정으로 로그인했다면 다른 기기에서도 동기화돼요.

**Q. 엣지에서 기본 테마나 색상을 바꿀 수 있나요?**
**설정** → **모양** → **테마** 에서 기본, 어두운(다크 모드), 시스템 설정 따르기 등 테마를 선택할 수 있어요. 마이크로소프트 스토어에서 추가 테마도 다운로드 가능해요.

## 요약

마이크로소프트 엣지는 윈도우 11의 기본 브라우저로, 크롬보다 배터리 소모가 적고 **AI 코파일럿**이 내장된 최신 브라우저예요. **즐겨찾기 동기화**로 여러 기기에서 같은 환경을 유지하고, **절전 탭**으로 PC 메모리를 절약하고, **세로 탭**으로 탭을 깔끔하게 관리할 수 있어요. PDF 편집, 코파일럿 AI, 번역 기능까지 활용하면 별도 프로그램 없이도 충분히 강력한 브라우저로 사용할 수 있어요.
