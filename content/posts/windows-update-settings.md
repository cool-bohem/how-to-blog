## 윈도우 업데이트란?

윈도우 업데이트(Windows Update)는 마이크로소프트가 배포하는 보안 패치, 기능 개선, 드라이버 업데이트 등을 자동으로 설치해 주는 기능입니다. 정기적인 업데이트는 컴퓨터를 바이러스와 해킹으로부터 보호하고 성능을 유지하는 데 매우 중요합니다.

그러나 업데이트가 중요한 작업 중에 갑자기 시작되거나, 업데이트 후 재시작이 필요해 불편을 주는 경우가 많습니다. 이 글에서는 윈도우 업데이트를 현명하게 관리하는 방법을 단계별로 설명해 드리겠습니다.

---

## 현재 업데이트 상태 확인 방법

### 업데이트 확인 및 수동 설치

1. 키보드의 **Windows 키 + I**를 눌러 설정 앱을 엽니다.
2. **Windows 업데이트** 항목을 클릭합니다(윈도우 10은 '업데이트 및 보안' 클릭 후 'Windows 업데이트' 선택).
3. **업데이트 확인** 버튼을 눌러 최신 업데이트가 있는지 확인합니다.
4. 사용 가능한 업데이트 목록이 표시되면 **모두 다운로드 및 설치** 버튼을 누릅니다.
5. 설치가 완료되면 **지금 다시 시작** 또는 **나중에 다시 시작** 중 선택합니다.

**팁**: 중요한 작업 전에는 반드시 먼저 업데이트를 수동으로 완료해 두세요. 그러면 작업 중 강제 업데이트 재시작을 방지할 수 있습니다.

---

## 업데이트 일시 중지(미루기) 방법

긴급한 업데이트를 일시적으로 미룰 수 있습니다.

### 윈도우 11에서 일시 중지

1. **설정** → **Windows 업데이트**로 이동합니다.
2. **업데이트 일시 중지** 항목에서 원하는 기간을 선택합니다.
   - 1주일 / 2주일 / 3주일 / 4주일 / 5주일 중 선택
3. 선택 즉시 업데이트 일시 중지가 적용됩니다.
4. 일시 중지를 해제하려면 같은 화면에서 **업데이트 재개** 버튼을 누릅니다.

### 윈도우 10에서 일시 중지

1. **설정** → **업데이트 및 보안** → **Windows 업데이트**로 이동합니다.
2. **고급 옵션**을 클릭합니다.
3. **업데이트 일시 중지** 옵션에서 날짜를 선택합니다(최대 35일까지 가능).

**주의**: 보안 패치 업데이트를 너무 오래 미루면 악성 소프트웨어나 해킹 위험이 높아집니다. 일시 중지 후 가능한 빨리 업데이트를 적용하세요.

## 활성 시간(업데이트 재시작 예외 시간) 설정

컴퓨터를 주로 사용하는 시간대를 설정하면 그 시간에는 자동으로 재시작되지 않습니다.

### 윈도우 11 활성 시간 설정

1. **설정** → **Windows 업데이트** → **고급 옵션**으로 이동합니다.
2. **활성 시간** 항목을 클릭합니다.
3. **수동** 또는 **자동(사용 패턴 기반)** 중 선택합니다.
   - **자동**: 윈도우가 사용 패턴을 분석해 자동으로 적절한 시간을 설정
   - **수동**: 직접 시작 시간과 종료 시간을 지정(최대 18시간 범위)
4. 수동 선택 시 예시: 오전 8시부터 오후 11시까지 설정하면 이 시간대에는 업데이트 재시작이 진행되지 않습니다.

## 업데이트 알림 및 예약 재시작 설정

### 재시작 예약하기

업데이트가 준비되었지만 지금 당장 재시작하기 어려울 때 예약 재시작을 사용합니다.

1. **설정** → **Windows 업데이트**로 이동합니다.
2. 업데이트 설치 완료 후 **다시 시작 예약** 옵션이 표시됩니다.
3. 원하는 날짜와 시간을 선택합니다(예: 오늘 밤 11시).
4. **예약** 버튼을 누르면 지정한 시간에 자동으로 재시작되어 업데이트를 완료합니다.

### 업데이트 알림 설정

1. **설정** → **Windows 업데이트** → **고급 옵션**으로 이동합니다.
2. **업데이트 시 사용자에게 알림** 항목을 켜면 업데이트 준비 완료 시 알림을 받을 수 있습니다.

## 특정 업데이트 숨기기/제거 방법

특정 업데이트가 문제를 일으키는 경우 제거하거나 숨길 수 있습니다.

### 문제 업데이트 제거

1. **설정** → **Windows 업데이트** → **업데이트 기록**으로 이동합니다.
2. **업데이트 제거** 버튼을 클릭합니다.
3. 제거할 업데이트를 찾아 선택 후 **제거** 버튼을 누릅니다.
4. 재시작 후 해당 업데이트가 제거됩니다.

### 업데이트 숨기기 (문제 업데이트 재설치 방지)

마이크로소프트의 **"업데이트 표시 또는 숨기기" 도구**를 활용합니다.

1. 마이크로소프트 공식 지원 페이지에서 **wushowhide.diagcab** 파일을 다운로드합니다.
2. 파일을 실행하여 진단 도구를 엽니다.
3. **업데이트 숨기기**를 선택한 후 숨기고 싶은 업데이트를 체크합니다.
4. 선택 완료 후 **다음** 버튼을 누르면 해당 업데이트가 숨겨져 자동 설치되지 않습니다.

## 드라이버 업데이트만 별도 관리하기

그래픽 카드, 사운드 카드 등 드라이버 업데이트는 따로 관리하는 것이 좋습니다.

### Windows 업데이트를 통한 드라이버 업데이트 끄기

1. **설정** → **Windows 업데이트** → **고급 옵션**으로 이동합니다.
2. **선택적 업데이트**를 클릭합니다.
3. **드라이버 업데이트** 탭에서 각 드라이버 업데이트의 설치 여부를 선택적으로 체크할 수 있습니다.

### 권장 방법: 제조사 공식 드라이버 사용

- **엔비디아(NVIDIA) GPU**: GeForce Experience 앱 또는 nvidia.com 공식 사이트에서 최신 드라이버를 직접 다운로드하세요.
- **AMD GPU**: AMD Radeon 소프트웨어 또는 amd.com에서 다운로드하세요.
- **인텔 드라이버**: Intel Driver & Support Assistant 프로그램을 사용하세요.

## 업데이트 관련 문제 해결

### 업데이트가 무한 대기/설치 실패하는 경우

1. **Windows 업데이트 문제 해결사 실행**
   - 설정 → 시스템 → 문제 해결 → 기타 문제 해결사 → Windows 업데이트 → **실행** 클릭
   - 문제 해결사가 자동으로 오류를 탐지하고 수정을 시도합니다.

2. **Windows 업데이트 서비스 재시작**
   - 검색창에 **"서비스"**를 입력하고 관리자 권한으로 실행합니다.
   - 목록에서 **Windows Update**를 찾아 우클릭 → **다시 시작**을 선택합니다.

3. **업데이트 캐시 삭제**
   - 검색창에 **"cmd"**를 입력 후 관리자 권한으로 실행합니다.
   - 다음 명령어를 순서대로 입력합니다:
     ```
     net stop wuauserv
     net stop cryptSvc
     net stop bits
     net stop msiserver
     ren C:\Windows\SoftwareDistribution SoftwareDistribution.old
     net start wuauserv
     net start cryptSvc
     net start bits
     net start msiserver
     ```
   - 완료 후 다시 업데이트를 시도합니다.

### 업데이트 후 속도가 느려진 경우

1. **설정** → **Windows 업데이트** → **고급 옵션** → **배달 최적화**로 이동합니다.
2. **다른 PC에서 다운로드 허용** 옵션을 **끔**으로 설정합니다.
   - 이 설정이 켜져 있으면 업데이트를 다른 PC와 공유하느라 인터넷 속도가 느려질 수 있습니다.

### 업데이트 후 특정 프로그램이 오류 나는 경우

최근 설치된 업데이트가 원인일 수 있습니다. 업데이트 기록에서 해당 날짜의 업데이트를 찾아 제거해 보세요.

## 자주 묻는 질문 (Q&A)

**Q. 윈도우 업데이트를 완전히 끌 수 있나요?**
A. 그룹 정책 편집기(gpedit.msc)나 레지스트리 편집을 통해 완전히 끄는 방법이 있지만, 마이크로소프트는 권장하지 않습니다. 보안 취약점이 생길 수 있으므로 일시 중지 기능을 활용하는 것이 안전합니다.

**Q. 업데이트 중에 전원을 끄면 어떻게 되나요?**
A. 파일 시스템이 손상될 수 있습니다. 업데이트 중에는 절대 강제 종료하지 마세요. 반드시 업데이트가 완료될 때까지 기다리세요. 진행이 멈춘 것처럼 보여도 최소 30분~1시간은 기다려보세요.

**Q. 윈도우 업데이트 용량이 너무 큰데 줄일 수 있나요?**
A. 누적 업데이트가 크게 느껴질 수 있습니다. 설정 → 시스템 → 저장 공간 → 임시 파일에서 "Windows 업데이트 정리"를 선택하면 이전 업데이트 백업 파일을 삭제할 수 있습니다(수 GB 확보 가능).

**Q. 업데이트 후 바탕화면이 바뀌었어요. 어떻게 하나요?**
A. 바탕화면 빈 공간에 우클릭 → 개인 설정 → 배경으로 가서 이전 사진을 다시 설정하면 됩니다.

## 마무리 정리

윈도우 업데이트는 컴퓨터 보안을 위해 꼭 필요하지만, 타이밍을 잘 관리해야 불편함을 줄일 수 있습니다.

- **활성 시간 설정**으로 업무 중 강제 재시작을 방지하세요.
- **업데이트 일시 중지**는 최대 5주까지 가능하지만 보안을 위해 빠른 업데이트를 권장합니다.
- **재시작 예약** 기능으로 사용하지 않는 시간(심야)에 업데이트를 완료하도록 설정하세요.
- 문제가 생기면 **문제 해결사**를 먼저 실행해 보세요.

현명한 업데이트 관리로 윈도우를 항상 최신 상태로 유지하면서도 불편함 없이 사용하세요!
